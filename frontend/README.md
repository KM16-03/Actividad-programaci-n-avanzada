# Frontend - Semana 2

## Descripción
Proyecto frontend de la aplicación de hábitos para la semana 2 del curso de Programación Avanzada.

## Tecnologías usadas
- Next.js
- React
- Redux Toolkit
- React Redux

## Funcionalidad realizada en semana 2
- Configuración inicial del proyecto en Next.js
- Configuración de Redux
- Request GET al backend para obtener hábitos
- Mostrar hábitos en pantalla
- Estructura del proyecto en carpeta frontend

## Cómo ejecutar
1. Abrir terminal en la carpeta frontend
2. Instalar dependencias con:
   npm install
3. Ejecutar el proyecto con:
   npm run dev

## URL local
http://localhost:3000
