Actividad Programación Avanzada

Semana 1 - Backend de hábitos

Este proyecto corresponde a la actividad de la semana 1 del curso de Programación Avanzada.

Tecnologías utilizadas
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- Dotenv
- Cors

Estructura del proyecto
- backend
- frontend

En esta semana se trabajó únicamente la carpeta backend.

Funcionalidades realizadas en semana 1
- Conexión de Express con MongoDB Atlas
- Creación del modelo de hábitos
- Ruta para obtener hábitos
- Ruta para crear hábitos
- Ruta para actualizar hábitos
- Ruta para eliminar hábitos

Instalación
1. Entrar a la carpeta backend
2. Ejecutar el comando:


npm install
